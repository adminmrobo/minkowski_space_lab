## 0편 「가방 점검」
- 히어로
  - 박사(doc_board): 시계가 걸린 복도에 들어가기 전에 가방 점검! 앞 복도에서 쓰던 도구 세 개를 꺼내 보죠.
  - 시아(sia_smile): 자, 각도기, 끝없는 방… 다 들고 왔어요!
  - 모아(moa_tea): 쌍곡선은 처음 들어 봐요. 그것도 가방에 있어야 해요?
  - 주판봇(robo_smile): 시간도 그냥 한 칸 더 붙이면 끝이지! 가방 같은 건 필요 없어.
- 가방 앞
  - 초파리(fly_point): 카드만 읽지 말고 실험 세 개를 직접 움직여 봐. 특히 세 번째.
  - 조수(asst_spark): 원과 쌍곡선, 식에서 부호 하나만 달라요. 숫자로 같이 확인해 봐요.
- 끝
  - 박사(doc_front): 오늘 복도에서는 "길이는 언제나 0 이상"이라는 규칙이 깨집니다. 놀라지 말고 들어오세요.
  - 시아(sia_guide): 1번 방부터 제가 앞장설게요!
  - 모아(moa_ok): 저는 부호 확인 담당이에요.

## ①편 「시계가 걸린 복도」
### 히어로
- 박사(doc_board): 이번 복도는 방마다 벽시계가 걸려 있어요. 점마다 "언제"가 붙습니다.
- 시아(sia_explain): 시간도 그냥 한 칸 더 붙이면 되죠? 4칸짜리 유클리드 방!
- 모아(moa_report): 그런데 시간은 초, 거리는 미터잖아요. 그냥 더해도 돼요?
- 조수(asst_report): 오늘 제 수식 상자에는 마이너스가 하나 등장합니다. 미리 경고해요.

### 대결 「원인 탐정」 (심판 조수)
- 조수(asst_firm): 규칙 두 줄! ① 거리²가 0 이하 ② B가 A보다 나중. 둘 다면 "원인 가능".
- 시아(sia_signal): 저는 원뿔 그림으로 한눈에 볼게요.
- 모아(moa_report): 저는 부호를 계산할게요.
- (카드 4) 시아(sia_think): 잠깐, 이건 원뿔 아래쪽이에요. B가 과거니까 불가! → X1~X3 박수.
- (카드 5·6) 시아가 테두리 근처에서 두 장을 헷갈림. 모아는 −0.99와 +0.99로 정확히 가름.
- 결과: 시아 4/6, 모아 6/6. 조수(asst_proud): 모아 승! 하지만 과거 쪽 카드를 먼저 잡은 건 시아예요.
