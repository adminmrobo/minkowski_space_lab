# 마이너스 칸이 있는 방 — 시아·모아의 민코프스키 시공간

공간 시리즈 세 번째 복도입니다. 유클리드 공간(자와 각도기의 방), 힐베르트 공간(끝없는 방)에 이어, 시간 칸 하나만 마이너스로 세는 **민코프스키 시공간**을 연구실 식구들과 함께 봅니다.

- 공개 주소: https://adminmrobo.github.io/minkowski_space_lab/ 
- 앞 편: [유클리드 · 힐베르트 공간](https://github.com/adminmrobo/hilbert_space_lab)
- 원자료: 인포그래픽 「Minkowski Space」(@askwhyvalley) — 그림은 이 페이지에서 다시 그렸습니다.

## 구성 (제작 중)
| 파일 | 내용 |
|---|---|
| `index.html` | 목차 |
| `m0_orientation.html` | 0편 「가방 점검」 — 자·끝없는 방의 규칙·쌍곡선 |
| `m1_clock_corridor.html` | ①편 「시계가 걸린 복도」 — 방 7개 + AI 답 검사 + 원인 탐정 대결 |
| `code/check_minkowski.js` | 본문 숫자 검산 (`node code/check_minkowski.js`) |
| `build/` | 페이지 조립 (`python3 build/kg_defs.py && node build/build.js`) |
| `docs/` | 기획안 · 사실 카드 · 캐릭터 대본 · 그림 지시문(픽셀아트) |
